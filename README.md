# 8-bit RISC CPU in Verilog

A custom 8-bit RISC-style CPU designed and implemented in Verilog HDL.

## Features
- Register File
- ALU
- Control Unit
- Instruction Memory
- Branching
- Data Forwarding
- Pipeline Hazard Handling
- GTKWave Simulation

## Tools Used
- Verilog HDL
- Icarus Verilog
- GTKWave
